# DDNSupd 0.1.1

Initial release for self-hosted DDNS management on Linux/amd64.

- Rust API, PostgreSQL, German/English Svelte portal and private Go engine.
- Hetzner Cloud and Cloudflare A/AAAA updates, scoped permissions and history.
- Confirmed creation of missing Hetzner A/AAAA records.
- Read-only zone/record discovery and staged configuration import.
- Encrypted backups, initial-setup recovery and optional daily rotation.
- IPv4/IPv6 egress and a Portainer stack.

## Portainer

Use repository `https://github.com/itsh-neumeier/ddnsupd`, reference
`refs/tags/v0.1.1` and Compose path `docker-compose.portainer.yml`.
Import the private environment values described in the installation guide.

Images are `ghcr.io/itsh-neumeier/ddnsupd:0.1.1` and
`ghcr.io/itsh-neumeier/ddnsupd-worker:0.1.1`. Both also have a `latest` tag.

## Scope

This is the first release. Only Linux/amd64 images are included. Recovery
requires a matching database schema and archives up to 16 MiB. Restored records
start paused. The provider matrix distinguishes mock evidence from live tests.
TOTP, password reset, notifications and additional providers remain planned.

The unreleased 0.1.0 build was stopped by its image scan. This release updates
the distroless runtime to include the zlib security fix for CVE-2026-85091.
