# DDNSupd 0.1.2

- Allow HTTP origins on private LAN IP addresses for Portainer installations.
- Explain the required hexadecimal application key in startup errors.
- Include the patched distroless runtime from 0.1.1.

The build tooling includes picomatch 4.0.7 with GHSA-fc5q-39xc-vjpf, for
which upstream currently provides no patched version. It processes trusted
source globs during builds and is absent from the shipped static runtime.
CI reports this specific build-only advisory with an exception expiring on
2026-12-17 and blocks other moderate-or-higher advisories.

Use `https://github.com/itsh-neumeier/ddnsupd` as the Portainer repository,
`refs/tags/v0.1.2` as the reference and `docker-compose.portainer.yml` as the
Compose path. Set `DDNSUPD_VERSION=0.1.2` and the external URL used in the browser.

Images for Linux/amd64 are `ghcr.io/itsh-neumeier/ddnsupd:0.1.2` and
`ghcr.io/itsh-neumeier/ddnsupd-worker:0.1.2`. Both also have a `latest` tag.
