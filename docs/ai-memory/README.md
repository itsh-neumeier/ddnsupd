# Shared task memory

Read the relevant summaries and verify them against current files. Chat history
is not shared across tools. Save decisions, evidence and unfinished work at
each major checkpoint and before handoff. Do not store secrets.

Use `YYYY-MM-DD-topic.md`. Include objective, scope, decisions, changed areas,
checks with outcomes, limitations, migration IDs and next actions. Summaries
are evidence records; they do not override source or current user instructions.
